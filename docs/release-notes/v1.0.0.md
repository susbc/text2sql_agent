# 溯算编程 · Text2SQL 智能体 v1.0.0

基于本地知识库的自然语言转 SQL 系统：Neo4j 知识图谱 + BM25/FAISS 混合检索 + 多模型 LLM，自动生成并执行 SQL。

## 本版本要点

- **嵌入式 SQLite 存储**：应用存储与 SQL 执行全部落在单文件 SQLite（`data/text2sql.db`），**无需安装/运行 MySQL 服务**，开箱自带示例业务数据（8 表 30 行）。
- **跨平台桌面安装包**：PyInstaller 打包，双击起本地服务并自动打开浏览器。
- **首跑配置向导**：系统信息页配置 LLM 与 Embedding，持久化到用户数据目录，重启不丢失。
- **安全边界**：生成 SQL 仅读业务表，应用内部表无条件禁查；只读单条 SELECT + LIMIT 收紧 + 超时看门狗。
- **开源协议 Apache 2.0**（含 LICENSE / NOTICE）。

## 安装前提

- **LLM（必需，二选一）**：
  - 本地 [Ollama](https://ollama.com)：`ollama pull gemma4:E4B` + `ollama pull bge-m3:latest`；
  - 或云端 API Key（OpenAI / DashScope / DeepSeek / 智谱 / Azure）+ DashScope embedding。
- **Neo4j（可选）**：知识图谱增强默认关闭；如需图谱检索，连接外部 Neo4j 并在配置启用。
- 无 Ollama 且未配云端 embedding 时，检索回退 TF-IDF（降级模式）。

## 数据目录

配置与数据存于用户数据目录（SQLite / logs / .env / semantic_models）：
- macOS：`~/Library/Application Support/text2sql-agent`
- Windows：`%LOCALAPPDATA%/text2sql-agent`
- Linux：`~/.local/share/text2sql-agent`
