====================================================================
溯算编程 Text2SQL 智能体 —— 首次运行说明（README_FIRST_RUN）
====================================================================

本软件把自然语言问题转换为 SQL 并在本地 SQLite 库上执行，返回业务数据。
v1 为自包含演示版：内置示例业务数据（8 张业务表、30 条示例记录），
无需安装任何数据库服务，启动后即可试用，例如提问：
「查询所有黑名单用户」。

--------------------------------------------------------------------
一、运行时前提（LLM / Embedding，二选一）
--------------------------------------------------------------------
应用本身不捆绑大模型，首次运行前请准备以下任一路线：

路线 A：本地 Ollama（无需 API Key）
  1. 安装并启动 Ollama（https://ollama.com）。
  2. 拉取两个模型（缺一不可）：
       ollama pull gemma4:E4B        # LLM：负责 SQL 生成
       ollama pull bge-m3:latest     # Embedding：负责语义检索
  3. Ollama 默认地址 http://localhost:11434，本机运行无需修改。

路线 B：云端 API（需要 API Key）
  - 在首跑向导/「模型配置」面板选择云端提供商（DashScope 通义千问 /
    OpenAI / DeepSeek / 智谱 AI / Azure OpenAI）并填写 API Key。
  - Embedding 建议配 DashScope text-embedding-v3（可与 LLM 用同一 Key）。
  - 注意：v1 安装包未包含 Anthropic (Claude) 提供商。

降级说明：未配置可用 Embedding 时，检索自动回退为 TF-IDF 关键词匹配
（降级模式：语义检索质量下降，应用仍可用）。

可选：Neo4j 知识图谱增强
  - 默认关闭，非必需。如需图谱增强检索，请自备外部 Neo4j 服务，
    在数据目录 .env 中设 NEO4J_ENABLED=true，并填写
    NEO4J_URI / NEO4J_USER / NEO4J_PASSWORD。

--------------------------------------------------------------------
二、安装与首次启动（按操作系统）
--------------------------------------------------------------------
【macOS】
  1. 打开 .dmg，把 text2sql-agent.app 拖入 Applications 文件夹。
  2. v1 未签名：首次打开会提示「无法验证开发者」。绕过方法（任选其一）：
     - 右键（或 Control+点按）应用 →「打开」→ 弹窗中再点「打开」；
     - 或「系统设置 → 隐私与安全性」→ 找到拦截提示 →「仍要打开」。
  3. 启动后自动打开浏览器（http://127.0.0.1:8501）。

【Windows】
  1. 双击 text2sql-agent-<版本>-windows-x64-setup.exe，按向导安装
     （默认安装到 C:\Program Files\text2sql-agent）。
  2. v1 未签名：SmartScreen 提示「Windows 已保护你的电脑」时，
     点「更多信息」→「仍要运行」。
  3. 用桌面/开始菜单快捷方式启动，自动打开浏览器。

【Linux】
  1. 赋予执行权限并运行：
       chmod +x text2sql-agent-<版本>-linux-x86_64.AppImage
       ./text2sql-agent-<版本>-linux-x86_64.AppImage
  2. 要求 glibc ≥ 2.35（Ubuntu 22.04 构建，兼容较新发行版）。
     需要 FUSE；若缺 libfuse2，可安装之，或改用：
       ./text2sql-agent-<版本>-linux-x86_64.AppImage --appimage-extract-and-run
  3. 启动后自动打开浏览器。

--------------------------------------------------------------------
三、首跑向导（配置自动持久化）
--------------------------------------------------------------------
  - 首次启动自动创建数据目录、写入 .env 默认模板、复制语义模型，
    并用内置种子数据建立 SQLite 库（幂等，重复启动不会重复导入）。
  - 浏览器自动打开；若 8501 端口被占用会自动递增，以实际打开的地址为准。
  - 「系统信息」页出现「首次运行引导」时，在「模型配置」面板分别配置
    LLM 与 Embedding（Ollama 或云端 Key），保存后自动写入数据目录 .env，
    重启不丢失。
  - 也可直接编辑数据目录中的 .env，修改后重启应用生效。

--------------------------------------------------------------------
四、数据目录位置（所有用户数据都在这里，安装包本体只读）
--------------------------------------------------------------------
  macOS   ：~/Library/Application Support/text2sql-agent
  Windows ：%LOCALAPPDATA%\text2sql-agent
            （通常即 C:\Users\<用户名>\AppData\Local\text2sql-agent）
  Linux   ：~/.local/share/text2sql-agent

目录内容：
  .env               配置（首跑模板生成，已有配置绝不覆盖）
  text2sql.db        SQLite 库（业务示例数据 + 查询历史 + 应用元数据）
  logs/app.log       运行日志（排查问题先看这里）
  semantic_models/   语义模型（首跑自安装包复制，可编辑）
  index_cache/       检索索引缓存（可选）

卸载不会删除数据目录；如需彻底清理请手动删除上述目录。

--------------------------------------------------------------------
五、停止与常见问题
--------------------------------------------------------------------
  - 停止：v1 无原生退出菜单。关闭浏览器标签后结束应用进程即可：
    macOS 右键 Dock 图标→退出（必要时强制退出）；Windows 任务管理器
    结束 text2sql-agent.exe；Linux 终端 Ctrl+C 或 kill 进程。
  - 浏览器没自动打开？手动访问 http://127.0.0.1:8501（端口占用会递增，
    实际端口见 logs/app.log）。
  - 提示「生成失败：LLM 服务调用失败」？检查 Ollama 是否启动、两个模型
    是否已拉取，或云端 API Key 是否正确、网络是否可达。
  - 想恢复初始状态？关闭应用后删除数据目录（或仅删除其中 .env），
    重新启动即回到首跑状态。
